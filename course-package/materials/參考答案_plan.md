## 第二步：三個功能插槽

**要做的功能**

| 插槽 | 函式 | 功能 | 規則 |
|---|---|---|---|
| 1 | `checkIn(enrollmentId)` | 按「簽到」記下目前時間；已簽到不能再簽 | R4 |
| 2 | `attendanceText(courseId)` | 課程清單的出席率文字：已簽到 ÷ 報名人數，四捨五入到整數 %；沒人報名顯示「—」 | R5 |
| 3 | `exportCsv(courseId)` | 下載該課程簽到名單 CSV，開頭加 UTF-8 BOM；欄位依 spec 第 8 節 | R6 |

**做法**：在 Codex 加入 `AI實作` 資料夾，貼上「用 Codex 一次補上三個功能」提示詞；Codex 讀 `AGENTS.md`、本檔與 `docs/spec.md`，只在三個預留位置（程式裡的「功能插槽」標記之間）寫函式，其他地方不動 → 打開 `signin.html` 逐項測試。

**這一步不做**

- 取消簽到、修改報名；不改插槽以外的程式

## 卡住時怎麼辦

- Codex 做不出來或額度用完：下載 `signin_完成版.html`（檔名就是 `signin.html`）覆蓋，接著做驗收與 Code Review
- 某一項驗收沒過：在同一個 Codex 對話用「錯誤回報四件套」，最後加一句「只改那個函式」
- 預覽是空白：確認有網路（sql.js 要從網路載入），按 F12 看 Console 紅字
- Code Review 時 Codex 額度用完：在瀏覽器按 Ctrl+U 看 signin.html 原始碼、全選複製，貼到一般聊天用聊天版提示詞（會變成附件，只做一次）
