# 需求訪談紀錄：教育訓練報名簽到

## 1. 訪談對象

- 王小芸，教學研究部行政專員，負責院內教育訓練的報名與簽到
- 張主任，教學研究部主任
- 訪談日期：2026-10-14

## 2. 訪談內容（口述整理，未修飾）

**小芸：**
我們每個月大概辦五場教育訓練，消防、感控、病安、個資這些，有幾堂是全院每年都要上的。現在報名是各單位窗口用 LINE 傳名單給我，或是交紙本，我再一個一個打進 Excel。

最麻煩的是有時候名額已經滿了，還是有人一直報進來，我要一個一個回去說不好意思。還有同一個人被他們單位報了兩次，我也是到最後對名單才發現。

上課那天我會印簽到單放門口，大家簽名。問題是字跡有時候看不出來是誰，然後我還要拿著簽到單對回 Excel，一個一個標有沒有到。一場四十個人，這樣弄完差不多要兩三個小時。

單位窗口也會一直來問我：「我們單位誰還沒上？」我就要翻 Excel 找給他。

我希望有個東西，可以先把課開好，大家報名我直接輸入，額滿就不能再報，同一個人不能報兩次。上課當天我拿筆電在門口，誰來就按一下簽到，最後直接看出席率，然後可以匯出給主任、給各單位。

**張主任：**
我主要想看每一堂課的出席率。報了名沒來的比例太高的話，下次要跟那個單位講。月底我們要回報，所以最好能匯出成 Excel 可以開的檔案。

資料先不要放在網路上，個資的東西我們很謹慎。先在小芸的電腦上用就好，之後好用再跟資訊室討論要不要做成正式的。
