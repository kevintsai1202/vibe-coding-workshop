# 訪談補充回答：教育訓練報名簽到

> 課堂練習用，內容虛構。實作演練 1 讓 AI 讀完《需求訪談紀錄.md》並發問後，從這裡找對應的答案複製給 AI。
> 不要一開始就把這份貼給 AI——先讓它自己發現哪裡不清楚，才是這一步要練的。

**問：每堂課要記哪些資料？**
答：課程名稱、上課日期、開始時間、地點、名額、時數。時數是給同仁累計教育訓練時數用的。

**問：報名要填哪些資料？**
答：員工編號、姓名、單位，三個都必填。員工編號是 E 開頭加四碼數字，例如 E1001。

**問：單位要自己打字還是用選的？**
答：用選的，不然會有人打「護理科」有人打「護理部」。單位有：護理部、醫務部、藥劑部、檢驗科、放射科、總務室、人資室、資訊室、教學研究部、社工室。

**問：名額滿了怎麼辦？**
答：顯示「名額已滿」，不能再報。要加開的話我會自己開一堂新的課。

**問：什麼算重複報名？**
答：同一個員工編號報同一堂課兩次就是重複，要顯示「已報名過」。同一個人報不同的課沒問題。

**問：誰會使用這個系統？要不要登入？**
答：只有我一個人在教學研究部的電腦上用，不用登入。

**問：怎麼簽到？**
答：上課當天我開著名單，同仁到了報員工編號，我在他那一列按「簽到」，系統記下簽到時間。簽過就不能再簽。

**問：沒報名的人臨時來上課怎麼辦？**
答：名額還沒滿的話，我先幫他報名，再按簽到。滿了就請他下次再來。

**問：出席率怎麼算？**
答：簽到人數除以報名人數。沒人報名的課就顯示「—」。

**問：要匯出什麼？**
答：每一堂課可以匯出一份簽到名單，欄位是：課程名稱、上課日期、員工編號、姓名、單位、簽到狀態、簽到時間。要能用 Excel 直接打開，中文不能亂碼。

**問：可以取消報名或刪除課程嗎？**
答：這次先不用，之後再說。

**問：資料要存在哪裡？**
答：先存在這台電腦的瀏覽器裡就好，重新整理或關掉再開資料要還在。月底我會匯出 CSV 備份。

**問：要不要通知、QR Code 簽到、跟人資系統連？**
答：都先不要。這次先做最基本的，好用再說。
