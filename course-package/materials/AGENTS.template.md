# 專案規矩（AI 每次動手前請先讀）

## 這是什麼專案

晴川醫院教學研究部的「教育訓練報名簽到表」。使用者是行政人員，不會寫程式，需求與規則寫在 `docs/spec.md`，開發步驟寫在 `docs/plan.md`。

## 檔案與技術

- 成品只有一個檔案 `signin.html`，CSS 與 JavaScript 都寫在裡面；不用框架、不用伺服器、不用安裝任何套件
- 以講師的基本版為起點；簽到、出席率、匯出 CSV 寫在 `// ===== 功能插槽 N …（開始）=====` 與 `（結束）` 標記之間
- 資料庫用 sql.js 1.13.0（SQLite），從 cdnjs 載入；每次資料變更後存到 localStorage
- 匯出 CSV 時開頭加 UTF-8 BOM（`\uFEFF`）

## 寫程式的規矩

- 畫面文字與訊息一律使用繁體中文
- 每個函式上面用一行中文註解說明它做什麼
- 所有 SQL 都用參數（`?`）傳值，不可以把使用者輸入接成 SQL 字串
- 使用者輸入的文字顯示到畫面前要跳脫 HTML（用 `esc()`），或用 `textContent`
- 規則（名額、重複報名、必填、重複簽到）要在程式裡檢查，不能只靠畫面
- 只改功能插槽之間的程式；插槽以外的基本版不要動
- 規格書沒寫的功能不要自己加

- 不要使用或要求真實的員工、病人資料
